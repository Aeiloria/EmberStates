## Integration rules

1. Prefer the canonical Aeiloria repository URL in new links.
2. Preserve the legacy simplyabbeyd-pixel URL as a redirect/provenance alias.
3. Do not invent per-chat URLs.
4. Keep agent infrastructure, recovery controls, and canon evidence distinct.
5. Record every future source addition in both the human-readable and machine-readable registries.
6. Use the CSV companion file for spreadsheet-friendly imports: [agent-source-index.csv](agent-source-index.csv).
