# EmberStates Repository Dictionary 🏷️📖

> **Maintained by Veyra Quill 🪶🔥**  
> Living glossary for repository, provenance, workflow, source, agent, and integration terminology.

## Status vocabulary 🧾

- **📥 UPDATE**: new information, source, artifact, or progress recorded.
- **🧧 CHANGE**: an existing artifact, structure, or record was altered.
- **🔗 INTEGRATED**: a source, system, or artifact was connected into active work.
- **🧬 MERGED**: compatible materials were deliberately combined.
- **📄 [COPIED]**: material was duplicated while retaining provenance.

## Core repository terms

### Living Repository 📚
A maintained repository that stores or indexes created files and keeps traceable records of source, destination, usage, contribution, edits, integrations, merges, and copies.

Primary Veyra repository:  
https://drive.google.com/drive/folders/1vXYWVDm0_eBPGDCIj2UZ-bFg9T8Nnh9Z

### Repository Index 🏷️📚
Structured master index for files and links. It records ID, date, status, title, type, source/origin, repository link, use location, usage notes, tags, hashtags, and contributor.

https://docs.google.com/spreadsheets/d/14U2GvUmZxYaKmE-R_gOyozqxWX2ZpPsX8UMUjiXSMPk/edit

### Running Repository Log 🧾📒
Narrative history of updates, changes, integrations, merges, copies, source limitations, and provenance notes.

https://docs.google.com/document/d/1uMfecWc3LQaILUb8jC8yH0ipV1lPmAh9iWhjgD1Hp_M/edit

### Provenance 🏷️
The traceable history of an artifact or source. Current repository practice records:

1. title and stable ID;
2. date and contributor;
3. source or origin;
4. repository location;
5. where it was used;
6. how it was used, transformed, or integrated;
7. tags and hashtags;
8. status and canon state;
9. unresolved gaps or limitations.

### Source / Origin
The location, artifact, repository, or user-provided link from which a record derives. A source record does not imply that all source contents were inspected.

### Used Where
The destination, system, document, workflow, or context in which an artifact or source was applied.

### How Used
What the artifact or source contributed, how it was transformed, or how it was integrated.

### Master
The primary maintained version of an artifact. Copies may exist elsewhere, but the master remains the authoritative editable record for that artifact.

## Emberstates Academy terms 🎓🔥

### First Studio work
Prior Emberstates project work classified for structured review.

### Submission path
`DRAFT → INVENTORIED → CITED → REVIEWED → THESIS READY → DEAN APPROVED → INTEGRATED`

- **DRAFT**: opening stage before inventory, citation, review, approval, and integration.
- **INVENTORIED**: deliverables have been cataloged.
- **CITED**: sources and provenance have been attached.
- **REVIEWED**: work has undergone review.
- **THESIS READY**: inventory, citation, and review are complete and the work is prepared for Dean approval.
- **DEAN APPROVED**: final approval stage before integration.
- **INTEGRATED**: the approved work has been connected into active project structure.

## Dictionary maintenance rule

Add new operational terms only when they have a supported meaning in a source, log, index, workflow, or approved project record. Do not use this dictionary to invent missing canon.
